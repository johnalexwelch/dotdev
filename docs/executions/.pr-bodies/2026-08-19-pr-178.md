## What this PR does

Integrates the Stream Deck MK.2 design handoff (Cowork session, Aug 2026) into the repo: retires the previous employer's Stream Deck configuration, aligns the tracked plugin inventory with the live app state, removes a destructive `install.sh` symlink over the Stream Deck app data directory, and stages the environment variables the upcoming deck scripts need — with public-repo data hygiene applied throughout (calendar names and the meeting→doc map stay in untracked files).
