# Dotfiles

Personal dotfiles and system configuration for macOS development environment, managed with GNU Stow.

**AI agents start here:** [`llms.txt`](llms.txt) is the doc index. [`openwiki/quickstart.md`](openwiki/quickstart.md)
is the maintained deep-dive (architecture, workflows, skills, ops) — regenerated by OpenWiki, don't hand-edit it.
`AGENTS.md`/`CLAUDE.md` at repo root just point there. `AI_ENVIRONMENT.md` (Part 1 = how work gets done,
Part 2 = what's installed & where) predates OpenWiki and is being folded in; treat `openwiki/` as the source of
truth where they disagree.

## Quick Start

```bash
# Clone the repository
git clone https://github.com/johnalexwelch/dotdev.git ~/dotdev

# Run the installation script
cd ~/dotdev
./install.sh

# Install pre-commit hooks
pre-commit install
```

## Standalone Scripts

These live in `scripts/` and aren't part of the `install.sh` machine-setup flow.
`hdev`/`hlog` are installed as shell commands (aliases in `.config/zsh`, stowed by
`install.sh`); the rest are run by hand as needed:

| Script | Purpose | Usage |
|--------|---------|-------|
| `hdev.sh` | Launch herdr workspace layout for a project | `hdev [project_dir] [--monitor\|--minimal]` (alias) |
| `hlog.sh` | Snapshot active herdr agent panes to daily log | `hlog` / `hlog --view` / `hlog --search` (alias) |
| `arc.sh` | Backup/restore Arc browser extensions & settings | `./scripts/arc.sh backup` / `restore` |
| `security-init.sh` | Init detect-secrets + git-secrets in a **repo** | Run inside each new repo, not at machine setup |
